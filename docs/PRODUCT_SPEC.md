# Selova Product Spec

Last updated: 2026-06-25

## 目的

Selova は、学習動画を最後まで見やすくし、途中で離脱しても再開しやすくする iOS アプリです。縦スワイプの軽さは使いつつ、無限スクロールではなく「理解して進む」ことに寄せます。

中心の問い:

- この機能は、学習者が動画を続ける・見終える・理解することにどう役立つのか？

## 現在の実装概要

この仕様は、現在の `README.md`、`CURRENT_APP_DETAILS.md`、ソース調査に基づきます。

- App entry: `FocusVideoApp/FocusVideoAppApp.swift`
- Main navigation: `FocusVideoApp/ContentView.swift`
- Main tabs: ホーム / ライブラリ
- Full-screen playback: `FocusVideoApp/Views/StudyFeedView.swift`
- Data models: `FolderItem`, `VideoItem`, `VideoNote`, `VideoAttentionEvent`, `StudySession`
- Storage: SwiftData
- Local playback: AVKit
- YouTube/Vimeo playback: WebView embed
- Notifications: `UNUserNotificationCenter` によるローカル通知
- Analytics: `FocusVideoApp/SelovaAnalytics.swift`
- Live Activity: `SelovaLiveActivity/` と `Shared/StudyResumeActivityAttributes.swift`

## 初回リリースの約束

Provisional:

- Selova は「保存した学習動画を、フォルダごとに続きから再開し、1本ずつ最後まで見やすくする」アプリとして初回リリースする。

なぜ必要か:

- 学習動画アプリとして最初に信頼されるには、派手な分析や通知よりも「追加した動画を迷わず再開できる」ことが重要なため。

初回リリースの must:

- ホームから続きの動画に戻れる。
- ライブラリでフォルダと動画を管理できる。
- ローカル動画、YouTube、Vimeo の動画を追加できる。
- 学習フィードで同じフォルダ内の未完了動画を切り替えられる。
- 再生位置、集中時間、完了状態が保存される。
- 既存自動テストと基本シミュレータ build が通る。

初回リリースの should:

- タイムスタンプ付きノートが学習中/学習後に使える。
- 離脱後の通知設定が分かりやすく、オフにできる。
- 集中の記録が Home から見られる。

初回リリースの later:

- Live Activity を主役にした復帰導線。
- 高度な分析 dashboard をもとにした機能改善。
- クラウド同期、アカウント、AI チューター。
- 内部 target/scheme 名の `Selova` への全面改名。

## 想定ユーザー

主ユーザー:

- 学習動画を保存し、途中から再開しながら見終えたい学習者。

副ユーザー:

- 利用状況をプライバシーに配慮して見たい開発者/運用者。

仮決定:

- 最初は「自分で学習動画を集めて、途中から再開しながら見終えたい学習者」を広く対象にする。
- 外部向け説明では、中学生開発者による開発中アプリとして低姿勢で説明する。

## プロダクト原則

- 新しい動画を探すより、途中の動画に戻る方を簡単にする。
- 罰ではなく、自然に 1 本を見終えやすくする。
- 動画追加や整理が、学習開始の邪魔にならないようにする。
- 振り返りは、次の学習行動につながる場合だけ強く出す。
- 分析はプロダクト改善のために使い、個人の学習内容を過度に見える形にしない。

## 現在の機能領域

### ホーム

現在:

- 初回/継続利用で表示が変わる。
- 今日の集中時間、連続学習、XP/レベル、成長イラスト、続きから見やすい動画、集中し直す候補を表示する。
- 設定と集中の記録を開ける。

なぜ必要か:

- なぜライブラリではなくホームを学習再開の起点にするのか？
- なぜ XP、連続学習、成長イラストが集中を妨げず動機になるのか？
- なぜ「集中し直す候補」を信頼して表示できるのか？

成功指標:

- ホームから学習セッションが開始される。
- 未完了動画に戻れる。
- 集中し直す候補から復習が始まる。

### ライブラリ

現在:

- フォルダ、階層フォルダ、動画、検索、並び替え、移動、編集、削除を扱う。
- 動画は必ずフォルダに所属する。

なぜ必要か:

- なぜ初期リリースでフラットな動画一覧ではなくフォルダ中心なのか？
- なぜ動画作成時にフォルダ選択を必須にするのか？

成功指標:

- 迷わず動画を追加できる。
- 後から動画を見つけて再開できる。
- 整理作業が学習開始を遅らせない。

### 動画追加

現在:

- ローカル動画、YouTube、Vimeo に対応する。
- 可能な場合は外部メタデータを取得する。
- 追加後は「今すぐ再生」確認を出さず、ライブラリに保存する。

なぜ必要か:

- なぜこの 3 種類の動画ソースが初期スコープとして妥当なのか？
- なぜ追加直後の即時再生をあえて省くのか？

成功指標:

- 保存した動画が再生できる。
- タイトルやサムネイルにより、後から見つけやすい。

### 学習フィード

現在:

- ホームまたはライブラリから全画面で開く。
- 同じフォルダの未完了動画を縦スワイプで切り替える。
- 再生位置、視聴時間、集中時間、スクロール離脱位置を保存する。
- 戻る操作に摩擦を持たせる。

なぜ必要か:

- なぜ全動画ではなく同じフォルダ内で循環するのか？
- なぜ離脱時の摩擦が集中を助け、邪魔になりすぎないのか？
- なぜ学習動画に縦フィード UI が合うのか？

成功指標:

- 集中して見続ける時間が伸びる。
- 動画完了が増える。
- 正しい位置から再開できる。

### ノート

現在:

- `VideoNote` が動画ごとのタイムスタンプ付きメモを保持する。

なぜ必要か:

- なぜ既存のメモアプリではなく Selova 内に必要なのか？
- なぜタイムスタンプ付きである必要があるのか？

成功指標:

- 学習中または学習後にメモが作られる。
- メモが再開時の文脈復帰に役立つ。

### 通知と復帰導線

現在:

- 学習離脱後にローカル通知を予約できる。
- 設定で通知のオン/オフ、上限、許可状態を扱う。
- Live Activity による復帰導線の実装がある。

なぜ必要か:

- なぜ自然な再訪を待つだけでなく、離脱後に通知するのか？
- なぜ現在の通知タイミングが適切なのか？

成功指標:

- 通知から学習に戻る。
- 通知がしつこいと感じられない。

### 分析

現在:

- `SelovaAnalytics` 経由でイベントを送る。
- 詳細は `ANALYTICS.md` にまとまっている。

なぜ必要か:

- 各イベントはどのプロダクト判断に使うのか？
- 学習アプリとして十分に安全なデータ設計になっているのか？

成功指標:

- 開発者が起動、学習開始、完了、離脱を把握できる。
- 個人の動画内容を過度に露出しない。

## 現時点の非ゴール

- SNS 的な公開フィード。
- AI チューターや自動コンテンツ生成。
- クラウド同期。
- アカウント機能。
- `FocusVideoApp` から `Selova` への内部 target/scheme 一括改名。
